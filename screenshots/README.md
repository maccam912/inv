# Screenshot Placeholders

This directory contains placeholder files for screenshots that should be added to the repository.

## Description of Required Screenshots

1. **dashboard.png** - Main dashboard showing overview statistics, warnings, and transfer suggestions
2. **lot_management.png** - Lot management screen showing the list of lots with details
3. **inventory_tracking.png** - Inventory tracking screen showing current stock levels
4. **reports.png** - Reports screen displaying usage analytics and expiration forecasts

## How to Replace These Placeholders

Take actual screenshots of the application running and replace these placeholder files with real PNG images of the same name.
